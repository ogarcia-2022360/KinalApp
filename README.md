# KinalApp

El proyecto es una API hecha en SpringBoot para un manejo de ventas.
Con clases como: Clientes, Usuarios, Ventas, Productos, DetalleVenta.

## Requisitos Previos
* **Java 21**
* **SpringBoot 4.0.2**
* **Maven**
* **MySQL**
* **IntelliJ IDEA**
* **Postaman**
* **GitHub**

## Cómo se Instala y se ejecuta
* **Descargar el archivo de la aplicacion desde el repositorio de GitHub**
* **Abrir el archivo en IntelliJ IDEA**
* **Ejecutar el programa en "KinalAppApplication.java"**
* **Hacer peticiones HTTP con la aplicacion de Postman**
